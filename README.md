Tela de Login - DevClub

Uma tela de login moderna e responsiva, feita com HTML e CSS, utilizando ícones do Boxicons e fontes do Google Fonts. Este projeto foi criado como parte dos estudos em front-end e pode ser usado como base para sistemas de autenticação.

 Funcionalidades

- Campo de usuário com ícone
- Campo de senha com ícone
- Checkbox "Lembrar minha senha"
- Link de recuperação de senha
- Link para cadastro de novo usuário
- Estilo com transparência e fundo com imagem
- Responsivo e estilizado com fontes modernas

Tecnologias Utilizadas

- HTML5  
- CSS3  
- Google Fonts (Poppins e Montserrat)  
- [Boxicons](https://boxicons.com/)  
- Imagem de fundo com `background-size: cover` e `backdrop-filter`
